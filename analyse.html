1. Présentation des données

Le jeu de données TitanicSurvival, disponible dans le package carData, contient des informations sur les passagers du Titanic.

L’objectif de cette analyse est d’étudier les caractéristiques des passagers et leur survie en fonction de différentes variables.

# Installer carData uniquement si nécessaire
if (!requireNamespace("carData", quietly = TRUE)) {

}

# Charger les données

3. Visualisation des données

3.1. Survie selon le sexe

# Tableau des proportions de survie selon le sexe
tab_sexe <- prop.table(
  table(TitanicSurvival$sex, TitanicSurvival$survived),
  margin = 1
)

# Affichage des pourcentages
round(tab_sexe * 100, 1)
##         
##            no  yes
##   female 27.3 72.7
##   male   80.9 19.1
# Graphique en barres
barplot(
  t(tab_sexe),
  col = c("salmon", "lightblue"),
  legend.text = c("Décédés", "Survivants"),
  main = "Répartition de la survie selon le sexe",
  xlab = "Sexe",
  ylab = "Proportion",
  ylim = c(0, 1)
)

4. Interprétation des résultats

4.1. Influence du sexe sur la survie

Le graphique permet de comparer les proportions de survivants chez les femmes et chez les hommes. Il met en évidence une différence de survie selon le sexe, avec une proportion de survivantes plus importante chez les femmes.

4.2. Influence de la classe sur la survie

Le graphique montre que la survie varie selon la classe des passagers. Les passagers de première classe présentent une proportion de survivants plus élevée que ceux de deuxième et de troisième classe.

4.3. Influence de l’âge sur la survie

Les boîtes à moustaches permettent de comparer la distribution des âges entre les survivants et les passagers décédés.

La comparaison des médianes et de la dispersion permet d’étudier les différences entre les deux groupes. Cependant, 263 valeurs d’âge sont manquantes, ce qui limite l’interprétation de ce graphique.

4.4. Conclusion

Cette analyse descriptive suggère que la survie des passagers du Titanic est associée à plusieurs caractéristiques, notamment le sexe et la classe.

Ces résultats restent descriptifs : ils ne permettent pas, à eux seuls, de démontrer une relation causale entre ces variables et la survie.

5. Utilisation du package TitanicPackage

library(TitanicPackage)

# Taux de survie selon le sexe
taux_survie(TitanicSurvival, "sex")
##   groupe effectif survivants taux_survie
## 1 female      466        339        72.7
## 2   male      843        161        19.1
# Taux de survie selon la classe
taux_survie(TitanicSurvival, "passengerClass")
##   groupe effectif survivants taux_survie
## 1    1st      323        200        61.9
## 2    2nd      277        119        43.0
## 3    3rd      709        181        25.5

Les résultats obtenus à l’aide de notre package TitanicPackage confirment les tendances observées dans l’analyse descriptive. Le taux de survie est nettement supérieur chez les femmes (72,7 %) par rapport aux hommes (19,1 %).

La classe des passagers est également associée à la survie : 61,9 % des passagers de première classe ont survécu, contre 43,0 % en deuxième classe et 25,5 % en troisième classe.

Ces résultats montrent que le sexe et la classe sont associés à des différences importantes de survie parmi les passagers du Titanic.
